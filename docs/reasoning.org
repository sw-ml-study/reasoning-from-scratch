* How to read and run this document

This is the implementation guide. The separate [[file:using-reasoning-model.org][usage guide]] explains
setup, commands and interpreting results. Each library block below has prose
explaining its purpose and method, and tangles back to the checked source.
The bounded real-checkpoint attempt appears at the end. Generated real-model
examples and learning sections require measured viability, not fixture-only claims.

The narrative begins with deciding whether an answer is right, then develops
the tokenizer, model, loader and inference-time methods in sw-MLPL, with prose
before every implementation block. Each library source block carries a =:tangle= target, and
=scripts/check-tangle= runs in the pre-commit gate to prove that tangling this
document reproduces every file it explains, byte for byte. The =.mlpl= files
remain the source of truth; when they change, this document is edited to
match, and the gate fails until it is.

Why a verifier comes before a model: the project's goal is to turn a plain
next-token predictor into a model that reasons, and the mechanism for that is
reinforcement learning from a *verifiable reward*. The reward is exactly the
function in this document. There is no reward model and no human labels; a
rollout scores one if its boxed answer verifies against the reference and zero
otherwise. Building the reward first means every later claim about accuracy is
measurable from the start. The full picture is in
[[file:how-base-becomes-reasoning.md][how-base-becomes-reasoning.md]].

** A five-minute primer

Three self-contained blocks, each complete enough to run on its own.

The first shows why normalization exists. Two answers that share almost no
characters denote the same number:

#+begin_src mlpl :tangle no
print("dfrac and a plain fraction look nothing alike:")
print("  ", "\\dfrac{14}{3}")
print("  ", "(14)/(3)")
print("but 14 divided by 3 is the same number either way:", 14 / 3)
#+end_src

The second shows the exact-rational decision that the verifier turns on. A
decimal is a rational, so a half is a half, but a truncated third is not a
third:

#+begin_src mlpl :tangle no
half = 1 / 2
third = 1 / 3
print("0.5 equals 1/2 exactly:       ", eq(0.5, half))
print("0.3333333333 equals 1/3:      ", eq(0.3333333333, third))
print("the difference is not nothing:", third - 0.3333333333)
#+end_src

The third is the shape of every scanner in this document: no regular
expressions, just an index walking forward:

#+begin_src mlpl :tangle no
def u:primer_digits_end(s, i) {
  "Index just past the run of digits starting at i.";
  n = str_len(s);
  j = i;
  while lt(j, n) * gt(at(tokenize_bytes(str_slice(s, j, 1)), 0), 47) * lt(at(tokenize_bytes(str_slice(s, j, 1)), 0), 58) {
    j = j + 1
  };
  j
}
print("digits end at index:", u:primer_digits_end("1234abc", 0))
print("no digits here:     ", u:primer_digits_end("abc", 0))
#+end_src

* The sources

** lib/text/text.mlpl
:PROPERTIES:
:CUSTOM_ID: lib-text-text-mlpl
:END:

Everything downstream reads strings a character at a time, so this module
comes first. sw-MLPL has no regular-expression engine and this project never
asks for one: the two places the reference implementation uses a pattern are
finding the last number in a response and splitting a tokenizer's input, and
both are ordinary scans. What the language does give us is
=str_slice=, =str_find=, =str_split=, =str_len= and byte conversion, all
indexed by character rather than byte, so a multi-byte character such as
=²= counts once.

The module comment is the file's first line, as the style gate requires.

#+begin_src mlpl :tangle ../lib/text/text.mlpl
# Character-indexed string scanning helpers that stand in for regular expressions: classes, search, trim, replace, brace matching, number recognition.
#+end_src

One accessor underpins every scan. It is deliberately *total*: a negative
index or one past the end yields the empty string rather than raising. That
single decision is what lets later scanners look one character behind the
start without guarding every call, and it was added after a crash proved the
guard-at-every-call discipline does not survive contact with real code.

#+begin_src mlpl :tangle ../lib/text/text.mlpl
def u:text_char_at(s, i) {
  "The single character at index i, or the empty string for a negative index or one past the end. Total, so scanners may look one character behind the start.";
  if lt(i, 0) {
    ""
  } else {
    str_slice(s, i, 1)
  }
}
#+end_src

The character classes are ASCII-only and each is written as arithmetic on the
byte value, because comparison builtins return 1 or 0 and multiplication is
therefore logical *and*. A non-ASCII character such as =é= or =²= is not a
letter or a digit here, which matters: the normalization rules treat Unicode
superscripts separately and must not mistake them for digits.

#+begin_src mlpl :tangle ../lib/text/text.mlpl
def u:text_is_digit(c) {
  "1 when c is one ASCII digit.";
  if str_eq(c, "") {
    0
  } else {
    b = tokenize_bytes(c);
    if tally(b) - 1 {
      0
    } else {
      gt(at(b, 0), 47) * lt(at(b, 0), 58)
    }
  }
}

def u:text_is_letter(c) {
  "1 when c is one ASCII letter.";
  if str_eq(c, "") {
    0
  } else {
    b = tokenize_bytes(c);
    if tally(b) - 1 {
      0
    } else {
      v = at(b, 0);
      gt(v, 64) * lt(v, 91) + gt(v, 96) * lt(v, 123)
    }
  }
}

def u:text_is_alnum(c) {
  "1 when c is one ASCII letter or digit.";
  u:text_is_digit(c) + u:text_is_letter(c)
}

def u:text_is_space(c) {
  "1 when c is a space, tab, newline, or carriage return.";
  str_eq(c, " ") + str_eq(c, "\t") + str_eq(c, "\n") + str_eq(c, "\r")
}
#+end_src

Search is built from the language's =str_find=, which only reports the first
match from the beginning. Scanning from an offset means slicing the tail and
adding the offset back, and finding the *last* match means walking forward
until no more are found. An empty needle is never found, which keeps
=u:text_find_last= from looping forever.

#+begin_src mlpl :tangle ../lib/text/text.mlpl
def u:text_find_from(s, needle, start) {
  "First character index of needle at or after start, or -1.";
  n = str_len(s);
  if gt(start, n) {
    0 - 1
  } else {
    found = str_find(str_slice(s, start, n - start), needle);
    if lt(found, 0) {
      0 - 1
    } else {
      start + found
    }
  }
}

def u:text_find_last(s, needle) {
  "Last character index of needle in s, or -1; an empty needle is never found.";
  if str_eq(needle, "") {
    0 - 1
  } else {
    last = 0 - 1;
    pos = u:text_find_from(s, needle, 0);
    while gt(pos, 0 - 1) {
      last = pos;
      pos = u:text_find_from(s, needle, pos + 1)
    };
    last
  }
}

def u:text_contains(s, needle) {
  "1 when needle occurs in s.";
  gt(str_find(s, needle), 0 - 1)
}

def u:text_starts_with(s, prefix) {
  "1 when s begins with prefix.";
  str_eq(str_slice(s, 0, str_len(prefix)), prefix)
}

def u:text_ends_with(s, suffix) {
  "1 when s ends with suffix.";
  n = str_len(s);
  k = str_len(suffix);
  if gt(k, n) {
    0
  } else {
    str_eq(str_slice(s, n - k, k), suffix)
  }
}
#+end_src

These four rewrite a string. =u:text_replace_all= advances past each
replacement so a replacement containing the needle cannot loop, and an empty
needle is a no-op for the same reason. =u:text_lower= converts through the
byte array, adding 32 only to bytes in the upper-case range, so non-ASCII
characters pass through untouched.

#+begin_src mlpl :tangle ../lib/text/text.mlpl
def u:text_trim(s) {
  "Strip leading and trailing whitespace characters.";
  n = str_len(s);
  a = 0;
  while lt(a, n) * u:text_is_space(u:text_char_at(s, a)) {
    a = a + 1
  };
  b = n;
  while gt(b, a) * u:text_is_space(u:text_char_at(s, b - 1)) {
    b = b - 1
  };
  str_slice(s, a, b - a)
}

def u:text_strip_chars(s, chars) {
  "Strip any characters of the set string chars from both ends.";
  n = str_len(s);
  a = 0;
  while lt(a, n) * u:text_contains(chars, u:text_char_at(s, a)) {
    a = a + 1
  };
  b = n;
  while gt(b, a) * u:text_contains(chars, u:text_char_at(s, b - 1)) {
    b = b - 1
  };
  str_slice(s, a, b - a)
}

def u:text_replace_all(s, needle, replacement) {
  "Replace every non-overlapping occurrence of needle, scanning left to right; an empty needle returns s unchanged.";
  if str_eq(needle, "") {
    s
  } else {
    out = "";
    pos = 0;
    k = str_len(needle);
    n = str_len(s);
    found = u:text_find_from(s, needle, 0);
    while gt(found, 0 - 1) {
      out = str_concat(out, str_concat(str_slice(s, pos, found - pos), replacement));
      pos = found + k;
      found = u:text_find_from(s, needle, pos)
    };
    str_concat(out, str_slice(s, pos, n - pos))
  }
}

def u:text_lower(s) {
  "ASCII lower-case; non-ASCII characters pass through unchanged.";
  if str_eq(s, "") {
    s
  } else {
    b = tokenize_bytes(s);
    decode_bytes(b + 32 * gt(b, 64) * lt(b, 91))
  }
}
#+end_src

Brace matching is what makes =\boxed{outer {inner} ok}= extract correctly
rather than stopping at the first closing brace. The scan counts depth and
returns -1 for an unbalanced input or an index that is not a brace at all,
so callers branch on data instead of catching an error.

#+begin_src mlpl :tangle ../lib/text/text.mlpl
def u:text_match_brace(s, open_index) {
  "Index of the brace closing the one at open_index, counting nested pairs, or -1 when unbalanced or not a brace.";
  if str_eq(u:text_char_at(s, open_index), "{") {
    depth = 0;
    i = open_index;
    n = str_len(s);
    result = 0 - 1;
    while lt(i, n) {
      c = u:text_char_at(s, i);
      if str_eq(c, "{") {
        depth = depth + 1
      } else {
        0
      };
      if str_eq(c, "}") {
        depth = depth - 1
      } else {
        0
      };
      if str_eq(c, "}") * (1 - gt(depth, 0)) {
        result = i;
        i = n
      } else {
        i = i + 1
      }
    };
    result
  } else {
    0 - 1
  }
}
#+end_src

This is the number recognizer, and it is the closest thing here to a regular
expression. It accepts an optional minus sign, then either an integer
fraction such as =14/3=, or digits with an optional decimal part and an
optional exponent. =u:text_last_number= scans left to right and keeps the
last match, which is what "the final number in the response" means.

#+begin_src mlpl :tangle ../lib/text/text.mlpl
def u:text_digits_end(s, i) {
  "Index just past the run of ASCII digits starting at i (equal to i when there is none).";
  n = str_len(s);
  j = i;
  while lt(j, n) * u:text_is_digit(u:text_char_at(s, j)) {
    j = j + 1
  };
  j
}

def u:text_number_end(s, i) {
  "End index of a number token starting at i (optional minus, then integer fraction, or decimal with optional exponent), or -1 when none starts there.";
  n = str_len(s);
  j = i;
  if str_eq(u:text_char_at(s, j), "-") {
    j = j + 1
  } else {
    0
  };
  if u:text_is_digit(u:text_char_at(s, j)) {
    j = u:text_digits_end(s, j);
    if str_eq(u:text_char_at(s, j), "/") * u:text_is_digit(u:text_char_at(s, j + 1)) {
      u:text_digits_end(s, j + 1)
    } else {
      if str_eq(u:text_char_at(s, j), ".") * u:text_is_digit(u:text_char_at(s, j + 1)) {
        j = u:text_digits_end(s, j + 1)
      } else {
        0
      };
      e = u:text_char_at(s, j);
      if str_eq(e, "e") + str_eq(e, "E") {
        k = j + 1;
        sign = u:text_char_at(s, k);
        if str_eq(sign, "+") + str_eq(sign, "-") {
          k = k + 1
        } else {
          0
        };
        if u:text_is_digit(u:text_char_at(s, k)) { u:text_digits_end(s, k) } else {
          j
        }
      } else {
        j
      }
    }
  } else {
    0 - 1
  }
}

def u:text_last_number(s) {
  "The last number token in s (leftmost-longest scan, as a regular-expression search would find), or the empty string.";
  n = str_len(s);
  i = 0;
  last = "";
  while lt(i, n) {
    stop = u:text_number_end(s, i);
    if gt(stop, 0 - 1) {
      last = str_slice(s, i, stop - i);
      i = stop
    } else {
      i = i + 1
    }
  };
  last
}
#+end_src

Chat control tokens such as =<|im_end|>= appear in model output and must not
reach the verifier. The guard counter is belt and braces: the loop already
terminates because each pass shortens the string.

#+begin_src mlpl :tangle ../lib/text/text.mlpl
def u:text_remove_control_tokens(s) {
  "Delete every <|...|> control-token span.";
  out = s;
  open = str_find(out, "<|");
  guard = 0;
  while gt(open, 0 - 1) * lt(guard, 100000) {
    close = u:text_find_from(out, "|>", open + 2);
    if gt(close, 0 - 1) {
      out = str_concat(str_slice(out, 0, open), str_slice(out, close + 2, str_len(out) - close - 2));
      open = str_find(out, "<|")
    } else {
      open = 0 - 1
    };
    guard = guard + 1
  };
  out
}
#+end_src

** lib/verify/extract.mlpl
:PROPERTIES:
:CUSTOM_ID: lib-verify-extract-mlpl
:END:

Given a model's free text, the first job is to find what it claims the answer
is. The convention the whole pipeline depends on is that the model writes its
final result inside =\boxed{...}=. This module finds that group and decides
what to do when it is missing.

These files need =lib/text/text.mlpl= loaded first. An =include= resolves
relative to the including file and cannot climb out of its directory, so
library modules declare their dependencies in the module comment and the
loader inlines them in order.

The dependency is stated in the module comment rather than nested as an
include, for the reason given above.

#+begin_src mlpl :tangle ../lib/verify/extract.mlpl
# Final-answer extraction: the last boxed group with brace matching, then the numeric or full-text fallbacks. Requires lib/text/text.mlpl included first (nested includes cannot climb directories).
#+end_src

The *last* box wins, because a response often shows work in intermediate
boxes before committing to an answer. Whitespace between the command and the
brace is tolerated. Three distinct failures are reported separately, which the
tests pin: no box at all, a box command not followed by a brace, and an
unbalanced brace.

#+begin_src mlpl :tangle ../lib/verify/extract.mlpl
def u:verify_last_boxed(text) {
  "ok(content) of the last \\boxed{...} group with balanced braces, or err({kind}) when there is no box, no brace, or an unbalanced brace.";
  at_box = u:text_find_last(text, "\\boxed");
  if lt(at_box, 0) {
    err({kind: "no_boxed", message: "no \\boxed command"})
  } else {
    i = at_box + 6;
    n = str_len(text);
    while lt(i, n) * u:text_is_space(u:text_char_at(text, i)) {
      i = i + 1
    };
    if str_eq(u:text_char_at(text, i), "{") {
      close = u:text_match_brace(text, i);
      if lt(close, 0) {
        err({kind: "unbalanced", message: "unbalanced braces after \\boxed"})
      } else {
        ok(str_slice(text, i + 1, close - i - 1))
      }
    } else {
      err({kind: "no_brace", message: "\\boxed not followed by a brace"})
    }
  }
}
#+end_src

When there is no box the caller chooses what happens, and the choice is not
cosmetic. Reinforcement learning scores with =boxed_only=, so an answer that
is correct but unboxed earns nothing and the model learns the format.
Measuring a base model uses =number_then_full=, which accepts the last bare
number, because a model that has never been taught to box its answers would
otherwise score zero for the wrong reason.

#+begin_src mlpl :tangle ../lib/verify/extract.mlpl
def u:verify_final_candidate(text, mode) {
  "Candidate answer string: the last boxed group stripped of spaces and dollar signs; else, by mode, the last number (number_only, number_then_full), the whole trimmed text (number_then_full), or the empty string (boxed_only).";
  trimmed = u:text_trim(text);
  if str_eq(trimmed, "") {
    ""
  } else {
    boxed = u:verify_last_boxed(trimmed);
    if is_ok(boxed) {
      u:text_strip_chars(u:text_trim(unwrap(boxed)), "$ ")
    } else {
      if str_eq(mode, "boxed_only") {
        ""
      } else {
        number = u:text_last_number(trimmed);
        if str_eq(number, "") {
          if str_eq(mode, "number_then_full") {
            trimmed
          } else {
            ""
          }
        } else {
          number
        }
      }
    }
  }
}
#+end_src

** lib/verify/normalize.mlpl
:PROPERTIES:
:CUSTOM_ID: lib-verify-normalize-mlpl
:END:

Two answers can denote the same value and share no characters: =\dfrac{14}{3}=
and =(14)/(3)=, or =90^\circ= and =90=. Normalization rewrites both sides into
one comparable form by applying thirteen rules in a fixed order. The order
matters; =docs/verifier-contract.md= is the specification and this module is
its implementation.

The module comment names the contract it implements and the dependency it
needs loaded first.

#+begin_src mlpl :tangle ../lib/verify/normalize.mlpl
# Ordered normalization of a candidate or reference answer into a comparable form (docs/verifier-contract.md). Requires lib/text/text.mlpl included first.
#+end_src

Two rules that only fire at the edges of the string. A leading =c.= or =b:=
is a multiple-choice label and is dropped; a =\text{...}= that wraps the
*entire* string is unwrapped. A partial =\text{}= is deliberately left alone,
matching the reference implementation, and the later brace-removal rule then
strips its braces so =a\text{b}c= becomes =a\textbc=.

#+begin_src mlpl :tangle ../lib/verify/normalize.mlpl
def u:verify_strip_choice_label(s) {
  "Drop a leading single-letter multiple-choice label followed by a period or colon and optional spaces.";
  if u:text_is_letter(u:text_char_at(s, 0)) {
    i = 1;
    n = str_len(s);
    while lt(i, n) * u:text_is_space(u:text_char_at(s, i)) {
      i = i + 1
    };
    mark = u:text_char_at(s, i);
    if str_eq(mark, ".") + str_eq(mark, ":") {
      i = i + 1;
      while lt(i, n) * u:text_is_space(u:text_char_at(s, i)) {
        i = i + 1
      };
      str_slice(s, i, n - i)
    } else {
      s
    }
  } else {
    s
  }
}

def u:verify_unwrap_text(s) {
  "Unwrap a \\text{...} that spans the whole string.";
  if u:text_starts_with(s, "\\text{") {
    close = u:text_match_brace(s, 5);
    if close - (str_len(s) - 1) {
      s
    } else {
      str_slice(s, 6, close - 6)
    }
  } else {
    s
  }
}
#+end_src

LaTeX sizing commands such as =\left= are followed by spaces that must go
with them, otherwise =\left( 1= would normalize to =( 1= and differ from
=(1=.

#+begin_src mlpl :tangle ../lib/verify/normalize.mlpl
def u:verify_remove_command_spaces(s, command) {
  "Delete every occurrence of a LaTeX command together with the spaces that follow it.";
  out = "";
  pos = 0;
  k = str_len(command);
  n = str_len(s);
  found = u:text_find_from(s, command, 0);
  while gt(found, 0 - 1) {
    out = str_concat(out, str_slice(s, pos, found - pos));
    pos = found + k;
    while lt(pos, n) * str_eq(u:text_char_at(s, pos), " ") {
      pos = pos + 1
    };
    found = u:text_find_from(s, command, pos)
  };
  str_concat(out, str_slice(s, pos, n - pos))
}
#+end_src

Unicode superscripts are mapped to ASCII and, when attached to an operand,
become an explicit exponent: =2²= is =2**2=, while a bare =²= is just =2=.
The long conditional chain is the language's idiom for a lookup table; there
is no literal map type, and building a record incrementally is not possible.

#+begin_src mlpl :tangle ../lib/verify/normalize.mlpl
def u:verify_superscript_digit(c) {
  "ASCII form of one Unicode superscript character, or the empty string when c is not one.";
  if str_eq(c, "⁰") {
    "0"
  } else {
    if str_eq(c, "¹") {
      "1"
    } else {
      if str_eq(c, "²") {
        "2"
      } else {
        if str_eq(c, "³") {
          "3"
        } else {
          if str_eq(c, "⁴") {
            "4"
          } else {
            if str_eq(c, "⁵") {
              "5"
            } else {
              if str_eq(c, "⁶") {
                "6"
              } else {
                if str_eq(c, "⁷") {
                  "7"
                } else {
                  if str_eq(c, "⁸") {
                    "8"
                  } else {

def u:verify_rewrite_group_command(s, command, prefix, suffix) {
  "Rewrite every command{a} as prefix a suffix and every command<space>c (single character) the same way.";
  out = "";
  pos = 0;
  k = str_len(command);
  n = str_len(s);
  found = u:text_find_from(s, command, 0);
  while gt(found, 0 - 1) {
    out = str_concat(out, str_slice(s, pos, found - pos));
    i = found + k;
    while lt(i, n) * str_eq(u:text_char_at(s, i), " ") {
      i = i + 1
    };

      close = u:text_match_brace(s, i);
      if lt(close, 0) {
        out = str_concat(out, str_slice(s, found, k));
        pos = found + k
      } else {
        out = str_concat(out, str_concat(prefix, str_concat(str_slice(s, i + 1, close - i - 1), suffix)));
        pos = close + 1
      }
    } else {
      if u:text_is_alnum(u:text_char_at(s, i)) {
        out = str_concat(out, str_concat(prefix, str_concat(u:text_char_at(s, i), suffix)));
        pos = i + 1
      } else {
        out = str_concat(out, str_slice(s, found, k));
        pos = found + k
      }

def u:verify_group_after(s, i) {
  "Record {text, next} for the group at i: a brace-matched group or one alphanumeric character after optional spaces; next is -1 when neither.";
  n = str_len(s);
  j = i;
  while lt(j, n) * str_eq(u:text_char_at(s, j), " ") {
    j = j + 1
  };

    close = u:text_match_brace(s, j);
    if lt(close, 0) {
      {text: "", next: 0 - 1}
    } else {
      {text: str_slice(s, j + 1, close - j - 1), next: close + 1}
    }
  } else {
    if u:text_is_alnum(u:text_char_at(s, j)) {
      {text: u:text_char_at(s, j), next: j + 1}

      {text: "", next: 0 - 1}
    }
  }
}

To decide that =0.5= and =1/2= are the same number, something has to evaluate
them. The reference implementation calls a symbolic algebra system; there is
none here, so this module provides exact rational arithmetic and the next one
provides a parser.

The single most consequential decision in the verifier is here: a decimal is
parsed as an exact rational, not a float. That is why =0.5= equals one half
while a truncated =0.3333333333= does *not* equal one third, matching the
reference exactly. An earlier draft of the contract predicted a
floating-point tolerance would be needed and that the truncated decimal would
wrongly compare equal; exact rationals avoided the problem entirely.

A value is a record: a numerator, a denominator, and a flag saying whether it
is still exact.

#+begin_src mlpl :tangle ../lib/verify/number.mlpl
# Exact-rational arithmetic with a floating fallback, so a decimal and a fraction compare exactly while roots and constants stay approximate.
#+end_src

Every array element in sw-MLPL is a double, so integers are exact only below
two to the fifty-third. That bound is named once here and consulted whenever
a result could cross it. The greatest common divisor uses magnitudes because
the language's modulo takes the sign of its left operand.

#+begin_src mlpl :tangle ../lib/verify/number.mlpl
def u:verify_exact_limit() {
  "Largest magnitude an exact numerator or denominator may reach before the value degrades to floating point.";
  9007199254740992
}

def u:verify_gcd(a, b) {
  "Greatest common divisor of two magnitudes, by Euclid.";
  x = abs(a);
  y = abs(b);
  while y {
    t = mod(x, y);
    x = y;
    y = t
  };
  x
}

def u:verify_float(v) {
  "An inexact value carrying only its floating magnitude.";
  {num: v, den: 1, exact: 0}
}

def u:verify_value(v) {
  "The floating magnitude of an exact or inexact value.";
  v.num / v.den
}
#+end_src

Construction is where exactness is won or lost. The result is reduced, the
sign is moved to the numerator so equal values have equal representations,
and if either part would exceed the exact limit the value degrades to a
float rather than silently reporting a wrong answer. =u:verify_combine= makes
that contagious: any operation involving an approximate value is
approximate.

#+begin_src mlpl :tangle ../lib/verify/number.mlpl
def u:verify_rational(n, d) {
  "An exact rational reduced to lowest terms with the sign in the numerator; degrades to floating point on a zero denominator or once a part exceeds the exact-integer limit.";
  if d {
    sign = if lt(d, 0) {
      0 - 1
    } else {
      1
    };
    g = u:verify_gcd(n, d);
    if g {
      num = sign * n / g;
      den = sign * d / g;
      if gt(abs(num), u:verify_exact_limit()) + gt(den, u:verify_exact_limit()) { u:verify_float(num / den) } else {
        {num: num, den: den, exact: 1}
      }
    } else {
      {num: 0, den: 1, exact: 1}
    }
  } else {
    u:verify_float(n / d)
  }
}

def u:verify_combine(a, b, n, d) {
  "Build the result of a binary operation: exact when both operands are exact, floating otherwise.";
  if a.exact * b.exact { u:verify_rational(n, d) } else { u:verify_float(n / d) }
}

A square root stays exact only when both parts are perfect squares, so
=sqrt(9/4)= is three halves exactly while =sqrt(2)= becomes approximate. This
is the honest boundary: the module never claims exactness it cannot
demonstrate.

    rd = u:verify_perfect_root(a.den);

Equality is the point of the whole module. Two exact values are compared by
cross-multiplication, which is exact as long as the cross-products themselves
stay under the limit. Otherwise, and whenever either side is approximate, the
comparison is numeric within a relative tolerance.

#+begin_src mlpl :tangle ../lib/verify/number.mlpl
def u:verify_equal_values(a, b) {
  "1 when two values are equal: cross-multiplied exactly when both are exact and within the integer limit, else within a relative tolerance of 1e-9.";
  both_exact = a.exact * b.exact;
  cross_small = lt(abs(a.num * b.den), u:verify_exact_limit()) * lt(abs(b.num * a.den), u:verify_exact_limit());
  if both_exact * cross_small {
    if a.num * b.den - b.num * a.den {
      0
    } else {
      1
    }
  } else {
    x = u:verify_value(a);
    y = u:verify_value(b);
    scale = reduce(:max, [1, abs(x), abs(y)]);
    1 - gt(abs(x - y), 0.000000001 * scale)
  }
}

A recursive-descent parser over the normalized string, producing one of those
values. The grammar is small on purpose: sums, products, powers, unary signs,
parentheses, =sqrt=, =pi=, =e=, and implicit multiplication. Anything else,
including a free symbol such as =x=, is reported rather than guessed at.

Each parsing function returns a record carrying success, the position it
reached, and the value, which is how a language without mutable references
threads parser state.

The module comment lists the two files that must be loaded before it.

#+begin_src mlpl :tangle ../lib/verify/expr.mlpl

#+end_src

Primaries are where recursion begins: a parenthesized expression, a call to
=sqrt=, a named constant, or a number. An unrecognized name is not an error in
the syntactic sense, it is the =symbolic= verdict, and the grader uses that
distinction to fall back to text comparison.

#+begin_src mlpl :tangle ../lib/verify/expr.mlpl
def u:verify_parse_primary(s, i) {
  "Parse a number, a parenthesized expression, sqrt applied to one, or a known constant; an unknown name is a symbolic failure.";
  pos = u:verify_skip(s, i);
  c = u:text_char_at(s, pos);
  if str_eq(c, "") {
    u:verify_fail("syntax", "unexpected end of input")
  } else {
    if str_eq(c, "(") {
      inner = u:verify_parse_expr(s, pos + 1);
      if inner.ok {
        after = u:verify_skip(s, inner.pos);
        if str_eq(u:text_char_at(s, after), ")") { u:verify_step(after + 1, inner.value) } else { u:verify_fail("syntax", "missing closing parenthesis") }
      } else {
        inner
      }
    } else {
      if u:text_is_digit(c) {
        u:verify_scan_number(s, pos)
      } else {
        if u:text_is_letter(c) {
          stop = u:verify_scan_name(s, pos);
          name = str_slice(s, pos, stop - pos);
          if str_eq(name, "sqrt") {
            open = u:verify_skip(s, stop);
            if str_eq(u:text_char_at(s, open), "(") {
              inner = u:verify_parse_expr(s, open + 1);
              if inner.ok {
                after = u:verify_skip(s, inner.pos);
                if str_eq(u:text_char_at(s, after), ")") { u:verify_step(after + 1, u:verify_sqrt(inner.value)) } else { u:verify_fail("syntax", "missing closing parenthesis after sqrt") }
              } else {
                inner
              }
            } else {
              u:verify_fail("syntax", "sqrt without an argument")
            }
          } else {
            if str_eq(name, "pi") {
              u:verify_step(stop, u:verify_float(pi()))
            } else {
              if str_eq(name, "e") { u:verify_step(stop, u:verify_float(e())) } else { u:verify_fail("symbolic", str_concat("free symbol: ", name)) }
            }
          }
        } else {
          u:verify_fail("syntax", str_concat("unexpected character: ", c))
        }
      }
    }
  }
}

Precedence lives in the shape of these three functions. Exponentiation binds
tighter than a unary minus, so =-2**2= is minus four; and it is
right-associative, so =2**3**2= is two to the ninth. =u:verify_starts_factor=
decides when juxtaposition means multiplication, which is what makes
=2(3+4)= and =3sqrt(4)= parse.

#+begin_src mlpl :tangle ../lib/verify/expr.mlpl
def u:verify_parse_power(s, i) {
  "Parse a primary optionally raised to a power; the exponent is right-associative and may carry a sign.";
  base = u:verify_parse_primary(s, i);
  if base.ok {
    pos = u:verify_skip(s, base.pos);
    if str_eq(u:text_char_at(s, pos), "*") * str_eq(u:text_char_at(s, pos + 1), "*") {
      exponent = u:verify_parse_unary(s, pos + 2);
      if exponent.ok { u:verify_step(exponent.pos, u:verify_pow(base.value, exponent.value)) } else {
        exponent
      }
    } else {
      base
    }
  } else {
    base
  }
}

def u:verify_parse_unary(s, i) {
  "Parse an optionally signed power; a leading minus binds looser than exponentiation.";
  pos = u:verify_skip(s, i);
  c = u:text_char_at(s, pos);
  if str_eq(c, "-") {
    inner = u:verify_parse_unary(s, pos + 1);
    if inner.ok { u:verify_step(inner.pos, u:verify_neg(inner.value)) } else {
      inner
    }
  } else {
    if str_eq(c, "+") { u:verify_parse_unary(s, pos + 1) } else { u:verify_parse_power(s, i) }
  }
}

def u:verify_starts_factor(c) {
  "1 when c can begin a factor, which is what makes implicit multiplication unambiguous.";
  u:text_is_digit(c) + u:text_is_letter(c) + str_eq(c, "(")
}
#+end_src

Products and sums are left-associative loops rather than recursion, so a long
expression does not deepen the stack. Both carry a failure record out of the
loop instead of raising, keeping the parser total.

#+begin_src mlpl :tangle ../lib/verify/expr.mlpl
def u:verify_parse_term(s, i) {
  "Parse a product: explicit star and slash operators plus implicit multiplication such as 2(3+4) or 3sqrt(2).";
  left = u:verify_parse_unary(s, i);
  if left.ok {
    value = left.value;
    pos = left.pos;
    failure = left;
    running = 1;
    while running {
      at = u:verify_skip(s, pos);
      c = u:text_char_at(s, at);
      is_star = str_eq(c, "*") * (1 - str_eq(u:text_char_at(s, at + 1), "*"));
      is_slash = str_eq(c, "/");
      implicit = u:verify_starts_factor(c);
      if is_star + is_slash + implicit {
        start = if implicit {
          at
        } else {
          at + 1
        };
        right = u:verify_parse_power(s, start);
        if right.ok {
          value = if is_slash { u:verify_div(value, right.value) } else { u:verify_mul(value, right.value) };
          pos = right.pos
        } else {
          failure = right;
          running = 0
        }
      } else {
        running = 0
      }
    };
    if failure.ok { u:verify_step(pos, value) } else {
      failure
    }
  } else {
    left
  }
}

def u:verify_parse_expr(s, i) {
  "Parse a sum of terms.";
  left = u:verify_parse_term(s, i);
  if left.ok {
    value = left.value;
    pos = left.pos;
    failure = left;
    running = 1;
    while running {
      at = u:verify_skip(s, pos);
      c = u:text_char_at(s, at);
      if str_eq(c, "+") + str_eq(c, "-") {
        right = u:verify_parse_term(s, at + 1);
        if right.ok {
          value = if str_eq(c, "+") { u:verify_add(value, right.value) } else { u:verify_sub(value, right.value) };
          pos = right.pos
        } else {
          failure = right;
          running = 0
        }
      } else {
        running = 0
      }
    };
    if failure.ok { u:verify_step(pos, value) } else {
      failure
    }
  } else {
    left
  }
}

The verdict. Grading composes everything above: normalize both sides, split
tuples, compare part by part, and return one or zero. This function is the
reward signal that reinforcement learning will optimize, so its edge cases are
not academic.

Five dependencies, all of which the demo runner inlines in order.

#+begin_src mlpl :tangle ../lib/verify/grade.mlpl

A bracketed, comma-separated answer is a tuple and its parts are compared
individually. The split only fires on top-level commas, so a nested tuple
stays whole, and an empty part abandons the split entirely rather than
producing a meaningless part.

#+begin_src mlpl :tangle ../lib/verify/grade.mlpl
def u:verify_bracket_depth(c, depth) {
  "Depth after reading one character: opening brackets add, closing brackets subtract.";
  depth + str_eq(c, "(") + str_eq(c, "[") + str_eq(c, "{") - str_eq(c, ")") - str_eq(c, "]") - str_eq(c, "}")
}

def u:verify_split_parts(text) {
  "Split a bracketed comma-separated answer into trimmed parts; anything else, and any split that would leave an empty part, stays one part. An empty input has no parts.";
  n = str_len(text);
  if n {
    first = u:text_char_at(text, 0);
    last = u:text_char_at(text, n - 1);
    opened = str_eq(first, "(") + str_eq(first, "[");
    closed = str_eq(last, ")") + str_eq(last, "]");
    if opened * closed {
      joined = "";
      piece = "";
      depth = 0;
      commas = 0;
      empty = 0;
      i = 1;
      while lt(i, n - 1) {
        c = u:text_char_at(text, i);
        if str_eq(c, ",") * (1 - depth) {
          trimmed = u:text_trim(piece);
          if str_eq(trimmed, "") {
            empty = 1
          } else {
            0
          };
          joined = if commas {
            str_concat(joined, str_concat("\n", trimmed))
          } else {
            trimmed
          };
          commas = commas + 1;
          piece = ""
        } else {
          depth = u:verify_bracket_depth(c, depth);
          piece = str_concat(piece, c)
        };
        i = i + 1
      };
      trimmed = u:text_trim(piece);
      if str_eq(trimmed, "") {
        empty = 1
      } else {
        0
      };
      joined = if commas {
        str_concat(joined, str_concat("\n", trimmed))
      } else {
        trimmed
      };
      if commas * (1 - empty) {
        str_split(joined, "\n")
      } else {
        str_split(text, "\n")
      }
    } else {
      str_split(text, "\n")
    }
  } else {
    str_split("", "")
  }
}
#+end_src

Two parts match if their text matches, or if both evaluate to equal numbers.
When either fails to evaluate, the comparison falls back to text with spaces
removed, so =x+1= matches =x + 1= but not =1+x=. Recognizing that last pair
would require symbolic simplification, which this project does not implement
and the contract says so plainly.

#+begin_src mlpl :tangle ../lib/verify/grade.mlpl
def u:verify_equivalent(left, right) {
  "1 when two already-normalized parts are equal as numbers, or, when either fails to evaluate, as strings compared with every space removed. Symbolic rearrangement is deliberately not recognized.";
  if str_eq(left, right) {
    1
  } else {
    a = u:verify_parse(left);
    b = u:verify_parse(right);
    if is_ok(a) * is_ok(b) {
      u:verify_equal_values(unwrap(a), unwrap(b))
    } else {
      str_eq(u:text_replace_all(left, " ", ""), u:text_replace_all(right, " ", ""))
    }
  }
}
#+end_src

The grader is total: an empty side, a mismatched part count, or unparsable
text all grade zero rather than raising. =u:verify_grade_response= is the
reward function itself, extraction mode included, and it is what chapter six
will call once per rollout.

#+begin_src mlpl :tangle ../lib/verify/grade.mlpl
def u:verify_grade(candidate, reference) {
  "1 when the candidate answer matches the reference: both normalize, split into the same number of parts, and every aligned pair is equivalent in order. Total: an empty or unparsable side grades 0 rather than raising.";
  if str_eq(candidate, "") + str_eq(reference, "") {
    0
  } else {
    left = u:verify_split_parts(u:verify_normalize(candidate));
    right = u:verify_split_parts(u:verify_normalize(reference));
    count = list_len(left);
    if count - list_len(right) {
      0
    } else {
      if count {
        matched = 1;
        i = 0;
        while lt(i, count) {
          if u:verify_equivalent(unwrap(list_get(left, i)), unwrap(list_get(right, i))) {
            0
          } else {
            matched = 0;
            i = count
          };
          i = i + 1
        };
        matched
      } else {
        0
      }
    }
  }
}

def u:verify_grade_response(response, reference, mode) {
  "Extract the final answer from a model response using the given fallback mode, then grade it. This is the reward function used by evaluation and reinforcement learning.";
  u:verify_grade(u:verify_final_candidate(response, mode), reference)
}

Datasets arrive as JSON Lines, one problem per line. That is not a stylistic
preference: =parse_json= rejects an array of objects by design, because
sw-MLPL arrays are homogeneous and numeric, so a heterogeneous list has no
representation. JSON Lines sidesteps the question, and the loader below adds
budgets, schema validation, and errors that name the offending field and
line.

The module owns the =u:eval_= prefix together with the harness.

#+begin_src mlpl :tangle ../lib/eval/data.mlpl
# Bounded loading and validation of MATH-style problem records from JSONL text, files, and small JSON arrays. Requires lib/text/text.mlpl included first.
#+end_src

Budgets are explicit and overridable, and every failure has one shape:
a kind, a line number, a field name, and a message. Six kinds appear across
the module and the tests pin each one.

The schema requires a problem and an answer, both strings, and permits a
solution, subject, identifier, and level. Level may be a number or a string

  "Require or permit one string-valued field; report a missing or wrongly typed field by name and line.";
  if has_field(record, name) {
    if str_eq(type_of(unwrap(record_get(record, name))), "string") {
      ok(1)
    } else {

    }
  } else {
    if required {
      u:eval_data_error("missing_field", line_no, name, str_concat("required field absent: ", name))
    } else {
      ok(1)
    }
  }
}

def u:eval_validate_record(record, line_no) {
  "Validate the MATH record schema: problem and answer strings, optional solution, subject, unique_id strings, optional numeric or string level.";
  u:eval_field_string(record, "problem", line_no, 1)?;
  u:eval_field_string(record, "answer", line_no, 1)?;
  u:eval_field_string(record, "solution", line_no, 0)?;
  u:eval_field_string(record, "subject", line_no, 0)?;
  u:eval_field_string(record, "unique_id", line_no, 0)?;
  if has_field(record, "level") {
    kind = type_of(record.level);
    if str_eq(kind, "array") {

        ok(record)
      }
    } else {
      if str_eq(kind, "string") {
        ok(record)
      } else { u:eval_data_error("type", line_no, "level", "level must be a scalar or a string") }
    }
  } else {
    ok(record)
  }
}

One line at a time, under its own character budget, with the parse error
carried through rather than raised. A trailing newline at the end of a file
would otherwise look like an empty final record, so it is counted away.

#+begin_src mlpl :tangle ../lib/eval/data.mlpl
def u:eval_parse_line(line, line_no, max_line_bytes) {
  "Parse one JSONL line within its character budget and validate its schema.";
  if gt(str_len(line), max_line_bytes) {
    u:eval_data_error("budget", line_no, "", "line exceeds max_line_bytes")
  } else {
    parsed = parse_json(line, {max_depth: 4, max_bytes: max_line_bytes * 4});
    if is_err(parsed) {
      u:eval_data_error("parse", line_no, "", err_message(parsed))
    } else {
      value = unwrap(parsed);
      if str_eq(type_of(value), "record") {
        u:eval_validate_record(value, line_no)
      } else {
        u:eval_data_error("type", line_no, "", "line is not a JSON object")
      }
    }
  }
}

  "Count lines while ignoring one trailing empty line left by a final newline.";
  n = list_len(lines);
  if n {
    if str_eq(unwrap(list_get(lines, n - 1)), "") {
      n - 1
    } else {
      n
    }
  } else {
    0
  }
}

The loop validates every line before returning, so a dataset is either
entirely usable or reported with the first thing wrong with it. Validation
happens once; the lines themselves are kept as text.

#+begin_src mlpl :tangle ../lib/eval/data.mlpl
def u:eval_load_jsonl_text(text, source, opts) {
  "Validate every line of JSONL text under the budgets and return a dataset record {source, lines, count}.";
  max_bytes = u:eval_data_opt(opts, "max_bytes", 4194304);
  max_records = u:eval_data_opt(opts, "max_records", 100000);
  max_line_bytes = u:eval_data_opt(opts, "max_line_bytes", 65536);
  if gt(str_len(text), max_bytes) {
    u:eval_data_error("budget", 0, "", "input exceeds max_bytes")
  } else {
    lines = str_split(text, "\n");
    count = u:eval_line_count(lines);
    if gt(count, max_records) {
      u:eval_data_error("budget", 0, "", "record count exceeds max_records")
    } else {
      i = 0;
      failure = ok(1);
      while i - count {
        checked = u:eval_parse_line(unwrap(list_get(lines, i)), i + 1, max_line_bytes);
        if is_err(checked) {
          failure = checked;
          i = count
        } else {
          i = i + 1
        }
      };
      if is_err(failure) {
        failure
      } else {
        ok({source: source, lines: lines, count: count})
      }
    }
  }
}

Some published files are a JSON array of objects, so this scanner rewrites one
into JSON Lines by tracking brace depth and string state, including escapes.
Braces inside strings do not split objects, and raw newlines inside a record
become spaces, because a pretty-printed array spreads each object over several
lines while JSON Lines needs one line each.

The character budget is not decoration. This scanner walks one character at a
time through the interpreter, and its cost grows with the square of the input:
measured at 15.5 ms for 400 characters and 135 ms for 1,600. It is the right
tool for a small array and the wrong one for anything large, which is why the
tokenizer import below scans with targeted searches instead.

#+begin_src mlpl :tangle ../lib/eval/data.mlpl
def u:eval_scan_step(state, c) {
  "Advance the JSON array scanner state {depth, in_string, escaped, seen_open, seen_close, start, pieces} by one character at index state.i over state.text.";
  if state.in_string {
    if state.escaped {
      state = {depth: state.depth, in_string: 1, escaped: 0, seen_open: state.seen_open, seen_close: state.seen_close, start: state.start, pieces: state.pieces, text: state.text, i: state.i}
    } else {
      if str_eq(c, "\\") {
        state = {depth: state.depth, in_string: 1, escaped: 1, seen_open: state.seen_open, seen_close: state.seen_close, start: state.start, pieces: state.pieces, text: state.text, i: state.i}
      } else {
        if str_eq(c, "\"") {
          state = {depth: state.depth, in_string: 0, escaped: 0, seen_open: state.seen_open, seen_close: state.seen_close, start: state.start, pieces: state.pieces, text: state.text, i: state.i}
        } else {
          0
        }
      }
    }
  } else {
    if str_eq(c, "\"") {
      state = {depth: state.depth, in_string: 1, escaped: 0, seen_open: state.seen_open, seen_close: state.seen_close, start: state.start, pieces: state.pieces, text: state.text, i: state.i}
    } else {
      if str_eq(c, "[") {
        if state.depth {
          0
        } else {
          state = {depth: 0, in_string: 0, escaped: 0, seen_open: 1, seen_close: state.seen_close, start: state.start, pieces: state.pieces, text: state.text, i: state.i}
        }
      } else {
        if str_eq(c, "]") {
          if state.depth {
            0
          } else {
            state = {depth: 0, in_string: 0, escaped: 0, seen_open: state.seen_open, seen_close: 1, start: state.start, pieces: state.pieces, text: state.text, i: state.i}
          }
        } else {
          if str_eq(c, "{") {
            begin = if state.depth {
              state.start
            } else {
              state.i
            };
            state = {depth: state.depth + 1, in_string: 0, escaped: 0, seen_open: state.seen_open, seen_close: state.seen_close, start: begin, pieces: state.pieces, text: state.text, i: state.i}
          } else {
            if str_eq(c, "}") {
              depth = state.depth - 1;
              pieces = if depth {
                state.pieces
              } else { u:eval_append_line(state.pieces, str_slice(state.text, state.start, state.i - state.start + 1)) };
              state = {depth: depth, in_string: 0, escaped: 0, seen_open: state.seen_open, seen_close: state.seen_close, start: state.start, pieces: pieces, text: state.text, i: state.i}
            } else {
              0
            }
          }
        }
      }
    }
  };
  state
}

def u:eval_append_line(text, line) {
  "Append one line to accumulated JSONL text, without a leading newline on the first line.";
  if str_eq(text, "") {
    line
  } else {
    str_concat(text, str_concat("\n", line))
  }
}

def u:eval_split_json_array(text, max_bytes) {
  "Rewrite a JSON array of objects as JSONL by scanning brace depth and string state; bounded by max_bytes characters because the scan is interpreted.";
  if gt(str_len(text), max_bytes) {
    u:eval_data_error("budget", 0, "", "array text exceeds max_bytes")
  } else {
    chars = str_split(text, "");
    n = list_len(chars);
    state = {depth: 0, in_string: 0, escaped: 0, seen_open: 0, seen_close: 0, start: 0, pieces: "", text: text, i: 0};
    i = 0;
    while i - n {
      state = {depth: state.depth, in_string: state.in_string, escaped: state.escaped, seen_open: state.seen_open, seen_close: state.seen_close, start: state.start, pieces: state.pieces, text: text, i: i};
      state = u:eval_scan_step(state, unwrap(list_get(chars, i)));
      i = i + 1
    };
    if state.seen_open {
      if state.depth {
        u:eval_data_error("parse", 0, "", "unbalanced braces in JSON array")
      } else {
        if state.in_string {
          u:eval_data_error("parse", 0, "", "unterminated string in JSON array")
        } else {
          if state.seen_close {
            ok(state.pieces)
          } else { u:eval_data_error("parse", 0, "", "unterminated JSON array") }
        }
      }
    } else {
      u:eval_data_error("parse", 0, "", "text is not a JSON array")
    }
  }
}

def u:eval_load_json_array(path, opts) {
  "Read a sandboxed JSON array file, rewrite it as JSONL, and validate it into a dataset record.";
  text = read_text(path);
  if is_err(text) {

def u:eval_run(dataset, responder, options) {
  "Evaluate a responder over a dataset: grade every problem, optionally write one JSONL record each, and return {total, correct, accuracy, elapsed_ms, provenance}. A responder failure stops the run and is returned as an error.";
  mode = u:eval_data_opt(options, "mode", "number_then_full");
  out_path = u:eval_data_opt(options, "out_path", "");
  verbose = u:eval_data_opt(options, "verbose", 0);
  limit = u:eval_data_opt(options, "limit", 0 - 1);
  total = u:eval_count(dataset);
  if gt(limit, 0 - 1) {
    if lt(limit, total) {
      total = limit
    } else {
      0
    }
  } else {
    0
  };
  correct = 0;
  index = 0;
  failure = ok(1);
  started = clock_ms();
  while lt(index, total) {
    graded = u:eval_grade_one(dataset, index, responder, mode);
    if is_err(graded) {
      failure = graded;
      index = total
    } else {
      result = unwrap(graded);
      correct = correct + result.correct;
      if str_eq(out_path, "") {
        0
      } else {
        line = u:eval_record_line(result.index, result.problem, result.reference, result.response, result.extracted, result.correct, result.elapsed_ms);
        if is_err(line) {
          failure = line;
          index = total
        } else { u:eval_write_line(out_path, unwrap(line), 1 - gt(index, 0)) }
      };
      if verbose {
        print("  ", result.index, if result.correct {
            "correct"
          } else {
            "wrong"
          }, "extracted:", result.extracted, "reference:", result.reference)
      } else {
        0
      };
      index = index + 1
    }
  };
  if is_err(failure) {
    failure
  } else {
    elapsed = clock_ms() - started;
    ok({total: total, correct: correct, accuracy: if total {
          correct / total
        } else {
          0
        }, elapsed_ms: elapsed, provenance: u:eval_provenance(options)})
  }
}

** lib/tokenizer/import.mlpl
:PROPERTIES:
:CUSTOM_ID: lib-tokenizer-import-mlpl
:END:

A real =tokenizer.json= is six megabytes of pretty-printed JSON holding a
151,643-entry vocabulary, a 151,387-entry merge list, and a handful of control
tokens. Two measured facts shape this module.

The first is that the document cannot be parsed in one call: =parse_json=
refuses an array of objects by design, and =added_tokens= is exactly that, so
the whole-document parse fails at byte 271. The import therefore locates each
section by anchor and parses the sections separately.

The second is cost. The parses themselves are fast, 242 ms for the vocabulary
and 274 ms for the merges, but composing the tables into one record and
returning it takes the full import to 17.4 seconds, because a record holding
151,643 fields is expensive to move across a call boundary. The answer is to
pay that once and keep a native binary cache: 5.5 MB, written in 107 ms and
read back in 173 ms, which is the path every later run takes.

The module needs the scanners and, for its error shape, the dataset loader.

#+begin_src mlpl :tangle ../lib/tokenizer/import.mlpl

#+end_src

Locating a section means finding its key, and the direction matters. A
vocabulary token can be the word =vocab=, so the string ="vocab"= really does
appear twice in this file; the real key is the first occurrence because it
precedes the object it introduces. The merge list closes the document, so the
last occurrence is the safe choice there. =u:tok_last_char= scans backwards
from the end, which is cheap because a well-formed document closes within a
few characters of its end.

#+begin_src mlpl :tangle ../lib/tokenizer/import.mlpl
def u:tok_key_first(text, key) {
  "Character index of the first occurrence of a quoted key, or -1. Safe for keys whose real occurrence precedes any vocabulary token of the same name.";
  str_find(text, str_concat("\"", str_concat(key, "\"")))
}

def u:tok_key_last(text, key) {
  "Character index of the last occurrence of a quoted key, or -1. Safe for a key that closes the document, such as the merge list.";
  u:text_find_last(text, str_concat("\"", str_concat(key, "\"")))
}

def u:tok_after(text, index, opener) {
  "Index of the first opening bracket of the given kind at or after index, or -1.";
  if lt(index, 0) {
    0 - 1
  } else { u:text_find_from(text, opener, index) }
}

def u:tok_last_char(text, wanted) {
  "Index of the last occurrence of a single character, scanning backwards from the end. Cheap even on a multi-megabyte document because a well-formed file closes within a few characters of its end.";
  i = str_len(text) - 1;
  found = 0 - 1;
  while gt(i, 0 - 1) {
    if str_eq(u:text_char_at(text, i), wanted) {
      found = i;
      i = 0 - 1
    } else {
      i = i - 1
    }
  };
  found
}

def u:tok_trim_trailing_comma(section) {
  "Strip trailing whitespace and one trailing comma, which is what separates a value from the key that follows it.";
  trimmed = u:text_trim(section);
  n = str_len(trimmed);
  if str_eq(u:text_char_at(trimmed, n - 1), ",") { u:text_trim(str_slice(trimmed, 0, n - 1)) } else {
    trimmed
  }
}

def u:tok_section(text, start, stop) {
  "Text between two character indexes, trimmed of the separator that follows it; an invalid span is the empty string.";
  if lt(start, 0) + lt(stop, start) {
    ""
  } else { u:tok_trim_trailing_comma(str_slice(text, start, stop - start)) }
}

BPE tokenizer is supported, and both halves of that claim are checked against
small windows of the document rather than a full parse.

def u:tok_validate_kind(text) {
  "Require a byte-level BPE tokenizer: the model section declares BPE and the document declares a byte-level decoder. Anything else is refused rather than mis-parsed.";
  model_at = u:tok_key_first(text, "model");
  vocab_at = u:tok_key_first(text, "vocab");

The two large tables. The vocabulary runs from the brace after its key to the
merge key that follows it; the merge list runs from its bracket to the
document's final closing bracket. Each is handed to =parse_json= as its own
complete value, which is why the array-of-objects restriction never comes up:
neither of these is one.

#+begin_src mlpl :tangle ../lib/tokenizer/import.mlpl
def u:tok_parse_vocab(text, budgets) {
  "Parse the vocabulary object, which maps each token string to its integer id. Its span runs from the brace after the vocabulary key to the merge key that follows it.";
  vocab_at = u:tok_key_first(text, "vocab");
  merges_at = u:tok_key_last(text, "merges");
  open_at = u:tok_after(text, vocab_at, "{");
  if lt(open_at, 0) + lt(merges_at, open_at) {
    u:tok_error("shape", "no vocabulary object before the merge list")
  } else {
    section = u:tok_section(text, open_at, merges_at);
    parsed = parse_json(section, budgets);
    if is_err(parsed) { u:tok_error("parse", str_concat("vocabulary: ", err_message(parsed))) } else {
      ok(unwrap(parsed))
    }
  }
}

def u:tok_parse_merges(text, budgets) {
  "Parse the merge list, an ordered array of strings each holding one pair separated by a space. It is the document's last array, so it ends at the final closing bracket.";
  merges_at = u:tok_key_last(text, "merges");
  open_at = u:tok_after(text, merges_at, "[");
  close_at = u:tok_last_char(text, "]");
  if lt(open_at, 0) + lt(close_at, open_at) {
    u:tok_error("shape", "no merge array")
  } else {
    parsed = parse_json(str_slice(text, open_at, close_at - open_at + 1), budgets);
    if is_err(parsed) { u:tok_error("parse", str_concat("merges: ", err_message(parsed))) } else {
      ok(unwrap(parsed))
    }
  }
}

The added tokens are the array of objects that =parse_json= will not take, and
they are also where a naive approach gets expensive. Rather than walking the
section character by character, these two readers jump directly to each =id=
and =content= field with =str_find=. The whole section is read in 53 ms.

#+begin_src mlpl :tangle ../lib/tokenizer/import.mlpl
def u:tok_quoted_after(text, index) {
  "Record {value, next} for the quoted string that follows index, honouring backslash escapes; next is -1 when there is no complete string.";
  open_at = u:text_find_from(text, "\"", index);
  if lt(open_at, 0) {
    {value: "", next: 0 - 1}
  } else {
    n = str_len(text);
    i = open_at + 1;
    value = "";
    closed = 0 - 1;
    while lt(i, n) {
      c = u:text_char_at(text, i);
      if str_eq(c, "\\") {
        value = str_concat(value, str_slice(text, i, 2));
        i = i + 2
      } else {
        if str_eq(c, "\"") {
          closed = i;
          i = n
        } else {
          value = str_concat(value, c);
          i = i + 1
        }
      }
    };
    if lt(closed, 0) {
      {value: "", next: 0 - 1}
    } else {
      {value: value, next: closed + 1}
    }
  }
}

def u:tok_number_after(text, index) {
  "Record {value, next} for the integer that follows index, skipping spaces; next is -1 when no digits follow.";
  n = str_len(text);
  i = index;
  while lt(i, n) * (1 - u:text_is_digit(u:text_char_at(text, i))) * (1 - str_eq(u:text_char_at(text, i), "-")) {
    i = i + 1
  };
  stop = u:text_number_end(text, i);
  if lt(stop, 0) {
    {value: 0, next: 0 - 1}
  } else {
    {value: unwrap(to_number(str_slice(text, i, stop - i))), next: stop}
  }
}

def u:tok_parse_added(text, budgets) {
  "Collect the added and control tokens by scanning for each id and content field in order. The generic array-to-JSON-Lines scanner is deliberately not used here: it walks one character at a time and its cost grows with the square of the input, which this document's added-token section is already large enough to feel.";
  added_at = u:tok_key_first(text, "added_tokens");
  stop_at = u:tok_key_first(text, "normalizer");
  open_at = u:tok_after(text, added_at, "[");
  if lt(open_at, 0) + lt(stop_at, open_at) {
    ok({names: [], ids: []})
  } else {
    section = u:tok_section(text, open_at, stop_at);
    names = "";
    ids = [];
    pos = 0;
    count = 0;
    running = 1;
    while running {
      id_at = u:text_find_from(section, "\"id\":", pos);
      if lt(id_at, 0) {
        running = 0
      } else {
        id_read = u:tok_number_after(section, id_at + 5);
        content_at = u:text_find_from(section, "\"content\":", id_read.next);
        if lt(id_read.next, 0) + lt(content_at, 0) {
          running = 0
        } else {
          content = u:tok_quoted_after(section, content_at + 10);
          if lt(content.next, 0) {
            running = 0
          } else {
            names = if count {
              str_concat(names, str_concat("\n", content.value))
            } else {
              content.value
            };
            ids = concat(ids, id_read.value);
            count = count + 1;
            pos = content.next
          }
        }
      }
    };
    if count {
      ok({names: str_split(names, "\n"), ids: ids})
    } else {
      ok({names: [], ids: []})
    }
  }
}

The native binary encoding round-trips any data value, so the parsed tables go
to disk once and come back in 173 ms. =u:tok_load= prefers the cache and falls
back to importing the document, which is what makes a cold checkout work and a
warm one fast.

def u:tok_cache_write(tables, path) {
  "Write the parsed tables to a native binary cache so later runs skip the text parse entirely.";

** lib/tokenizer/bpe.mlpl
:PROPERTIES:
:CUSTOM_ID: lib-tokenizer-bpe-mlpl
:END:

Byte-level BPE in three parts: an alphabet that makes every byte printable,
a pre-tokenizer that decides where words begin, and a merge loop that walks a
word up the vocabulary.

One measurement shapes this module's status. It is correct: =hello= encodes to
14990 and a leading-space =the= to 279, matching their vocabulary entries. It
is also far too slow for production, because every symbol and every candidate
pair costs a vocabulary lookup, and a lookup on a 151,643-field record takes
34 ms. Encoding =hello world= takes 5.9 seconds. So this file is the readable
oracle that the native extension in =../demo-extensions= is checked against,
and the extension is what the evaluation and training sagas will call.

The module comment records that status, and the two files it needs first.

#+begin_src mlpl :tangle ../lib/tokenizer/bpe.mlpl
# Byte-level BPE encoding: the byte-to-character map, pre-tokenization, and the merge loop. This is the readable reference the native extension is checked against, not the production path. Requires lib/text/text.mlpl and lib/tokenizer/import.mlpl included first.
#+end_src

The byte alphabet exists so that a tokenizer can treat arbitrary bytes as
text. Printable bytes stand for themselves; every other byte is lifted above
255 in ascending order. The consequence worth noticing is that a space becomes
a visible marker character and a line feed becomes code point 266, so a mapped
string contains no whitespace at all. That is what makes it safe to hold a
symbol list as one newline-separated string a few functions below.

#+begin_src mlpl :tangle ../lib/tokenizer/bpe.mlpl
def u:tok_printable_byte(b) {
  "1 when a byte maps to itself in the byte-level alphabet: the printable ASCII range and two Latin-1 ranges.";
  gt(b, 32) * lt(b, 127) + gt(b, 160) * lt(b, 173) + gt(b, 173) * lt(b, 256)
}

def u:tok_byte_codepoint(b) {
  "Code point that represents one byte in the byte-level alphabet. Printable bytes stand for themselves; every other byte is lifted above 255 in ascending order, which is what makes a space appear as the marker character rather than as whitespace.";
  if u:tok_printable_byte(b) {
    b
  } else {
    if lt(b, 33) {
      256 + b
    } else {
      if lt(b, 161) {
        256 + 33 + b - 127
      } else {
        323
      }
    }

This is the trick that makes the encoder possible at all. Real BPE picks the
adjacent pair with the lowest merge rank, which normally needs a map from pair
to rank, and this language cannot build a 151,387-entry map cheaply.

It turns out not to need one. Checking all 151,387 merges of the real
tokenizer shows that the vocabulary id of the token a merge produces is
exactly the merge's rank plus 256, with no exceptions. So the vocabulary is
already the rank table, and the lowest id is the highest priority. The
function verifies that invariant rather than assuming it, and refuses a
tokenizer where it does not hold.

#+begin_src mlpl :tangle ../lib/tokenizer/bpe.mlpl
def u:tok_merge_base(tables, stride) {
  "Verify and return the offset between a merge's rank and the vocabulary id of the token it produces. Every merge is checked when stride is 1, otherwise every stride-th one. The encoder depends on this invariant: it uses the vocabulary id as the merge priority instead of building a rank table, which the language cannot construct cheaply for a list of this size.";
  count = u:tok_merge_count(tables);
  if count {
    first = u:tok_merge_joined(tables, 0);
    base_id = u:tok_token_id(tables, first);
    if is_err(base_id) {
      u:tok_error("invariant", "the first merge does not produce a vocabulary token")
    } else {
      base = unwrap(base_id);
      i = 0;
      failure = ok(base);
      while lt(i, count) {
        token = u:tok_merge_joined(tables, i);
        found = u:tok_token_id(tables, token);
        if is_err(found) {
          failure = u:tok_error("invariant", str_concat("merge produces no vocabulary token: ", token));
          i = count
        } else {
          if unwrap(found) - (base + i) {
            failure = u:tok_error("invariant", str_concat("merge rank and vocabulary id disagree at: ", token));
            i = count
          } else {
            i = i + stride
          }
        }
      };
      failure
    }
  } else {
    u:tok_error("invariant", "no merges")
  }
}

One merge step scans for the best pair and rebuilds the list around it.
=u:tok_merge_all= repeats until nothing may be merged, which terminates because
every step removes exactly one symbol.

#+begin_src mlpl :tangle ../lib/tokenizer/bpe.mlpl
def u:tok_merge_once(tables, symbols, base, count) {
  "Apply the single highest-priority merge available in a symbol list; returns the new list, or the list unchanged when nothing may be merged.";
  n = list_len(symbols);
  best = 0 - 1;
  best_at = 0 - 1;
  i = 0;
  while lt(i, n - 1) {
    priority = u:tok_pair_priority(tables, unwrap(list_get(symbols, i)), unwrap(list_get(symbols, i + 1)), base, count);
    if gt(priority, 0 - 1) {
      if lt(best, 0) + lt(priority, best) {
        best = priority;
        best_at = i
      } else {
        0
      }
    } else {
      0
    };
    i = i + 1
  };
  if lt(best_at, 0) {
    symbols
  } else {
    out = "";
    j = 0;
    while lt(j, n) {
      piece = if j - best_at {
        unwrap(list_get(symbols, j))
      } else {
        str_concat(unwrap(list_get(symbols, j)), unwrap(list_get(symbols, j + 1)))
      };
      out = if j {
        str_concat(out, str_concat(u:tok_symbol_separator(), piece))
      } else {
        piece
      };
      j = if j - best_at {
        j + 1
      } else {
        j + 2
      }
    };
    str_split(out, u:tok_symbol_separator())
  }
}

def u:tok_merge_all(tables, symbols, base, count) {
  "Merge repeatedly until no pair may be merged. Each pass removes one symbol, so the loop is bounded by the symbol count.";
  current = symbols;
  remaining = list_len(symbols);
  while gt(remaining, 1) {
    merged = u:tok_merge_once(tables, current, base, count);
    if list_len(merged) - list_len(current) {
      current = merged;
      remaining = list_len(merged)
    } else {
      remaining = 0
    }
  };
  current
}

Pre-tokenization decides where one word ends and the next begins, and it
matters more than it looks: the same characters split differently produce
entirely different ids. The published rule is a regular expression with seven
alternatives, and this is a hand-written approximation of it, so the divergence
is stated plainly. The published pattern uses Unicode letter and number
categories; this reference recognizes only ASCII, so text in a non-Latin
script splits differently here than in the native tokenizer. Latin text,
digits, punctuation, and whitespace follow the published behavior.

Three jobs that all work over token ids and strings rather than over model
weights: turning ids back into text, keeping control tokens out of the
byte-level machinery, and rendering a prompt the way each model kind was
trained to receive it. None of this moves to the native extension; it stays
MLPL after the encoder is replaced, because it is convention rather than
computation.

Decoding needs the opposite of a vocabulary lookup, an id to its token, and
that is where the language's container cost bites again. Scanning 151,643
keys is out of the question. What makes it tractable is that the vocabulary is
written one entry per line in id order, so line id plus one holds the entry,
and a byte-level token can never contain a real line break to break that
correspondence. The reader checks the line's own id rather than trusting the
ordering.

The module needs the scanners, the import, and the encoder's alphabet.

The inverse alphabet. Each character of a token stands for one byte, so
decoding is a code point per character, mapped back and handed to the byte
decoder. The round trip is checked for all 256 byte values in the tests.

#+begin_src mlpl :tangle ../lib/tokenizer/template.mlpl
def u:tok_char_codepoint(c) {
  "Code point of a single character, decoded from its UTF-8 bytes. Only the one and two byte forms occur in the byte-level alphabet.";
  b = tokenize_bytes(c);
  if tally(b) - 1 {
    64 * (at(b, 0) - 192) + at(b, 1) - 128
  } else {
    at(b, 0)
  }
}

def u:tok_codepoint_byte(cp) {
  "The byte a code point stands for in the byte-level alphabet: the inverse of the mapping the encoder applies.";
  if lt(cp, 256) {
    cp
  } else {
    if lt(cp, 289) {
      cp - 256
    } else {
      if lt(cp, 323) {
        cp - 256 - 33 + 127
      } else {
        173
      }
    }
  }
}

  };

    failure
  } else {
    ok(ids)
  }

The model itself, and the first code here that could not be an extension:
every operation below has to sit on the autograd tape, because reinforcement
learning in a later saga differentiates through all of it.

Two measurements dictate the style. Whole-array arithmetic is fast, at 1.28 ms
for a thousand-by-thousand matrix-vector product, while reaching into a
container copies it, at 0.97 ms for a single element of a million-element
array. So nothing here indexes inside a loop, with one exception that is
forced: attention must be computed per head because `matmul` accepts only
rank-2 operands, and that exception is precisely what upstream request R3
would remove.

The tiny configuration is not a toy version of the model. It is the same
functions at a smaller width, so a property that holds here is a property of
the code the real weights will run through.

The module comment states the indexing rule and the one exception.

Normalization works over the last axis at any rank, so it needs the shape
with that axis replaced by one in order to broadcast a per-row result back
over the rows. Building that shape from `shape(x)` is what these two helpers
do, and it is why the same normalization serves both a
`[positions, width]` block and a `[positions, heads, head_dim]` one.

#+begin_src mlpl :tangle ../lib/qwen3/qwen3.mlpl
def u:qwen_last_axis(x) {
  "Index of an array's last axis.";
  tally(shape(x)) - 1
}

def u:qwen_keepdim_shape(x) {
  "The shape of an array with its last axis replaced by one, so a per-row reduction can be broadcast back over it.";
  s = shape(x);
  n = tally(s);
  concat(compress(1 - eq(range(n), n - 1), s), 1)
}
#+end_src

Root-mean-square normalization. No mean is subtracted, which is the
difference from layer normalization and the reason it is cheaper: one
reduction, one square root, one scale.

#+begin_src mlpl :tangle ../lib/qwen3/qwen3.mlpl
def u:qwen_rms_norm(x, scale, eps) {
  "Root-mean-square normalization over the last axis, scaled by a learned gain. No mean is subtracted, which is what distinguishes this from layer normalization.";
  axis = u:qwen_last_axis(x);
  width = at(shape(x), axis);
  mean_square = reduce(:add, x * x, axis) / width;
  x / reshape(sqrt(mean_square + eps), u:qwen_keepdim_shape(x)) * scale
}
#+end_src

Rotary position embedding encodes a token's position by rotating its query
and key vectors, with the rotation angle growing linearly in position and
falling geometrically across the head. The tables are built once per
configuration. Each is its half repeated, because the rotation pairs feature
*i* with feature *i + head_dim/2* rather than with its neighbour.

#+begin_src mlpl :tangle ../lib/qwen3/qwen3.mlpl
def u:qwen_rope_tables(head_dim, base, context) {
  "Cosine and sine tables for rotary position embedding, computed once per configuration. Frequencies fall geometrically across half the head, and each table is that half repeated, which is what the split-halves rotation expects.";
  half = head_dim / 2;
  inverse_frequency = exp(0 - 2 * range(half) / head_dim * log(base));
  angles = matmul(reshape(range(context), [context, 1]), reshape(inverse_frequency, [1, half]));
  {cos: concat(cos(angles), cos(angles), 1), sin: concat(sin(angles), sin(angles), 1)}
}
#+end_src

Splitting a head in half is a `compress` along the last axis, which keeps
the operation whole-array. The rotation then negates the second half into the
first, which is the split-halves convention the published weights expect; the
interleaved convention would produce different numbers from the same
weights.

#+begin_src mlpl :tangle ../lib/qwen3/qwen3.mlpl
def u:qwen_first_half_mask(head_dim) {
  "Mask selecting the first half of a head's features.";
  lt(range(head_dim), head_dim / 2)
}

def u:qwen_apply_rope(x, tables, offset) {
  "Rotate a [positions, head_dim] block by its position angles. The rotation pairs each feature with the one half a head away, so the first half is negated into the second.";
  positions = at(shape(x), 0);
  head_dim = at(shape(x), 1);
  rows = range(positions) + offset;
  first = u:qwen_first_half_mask(head_dim);
  rotated = concat(0 - compress(1 - first, x, 1), compress(first, x, 1), 1);
  x * gather_rows(tables.cos, rows) + rotated * gather_rows(tables.sin, rows)
}
#+end_src

A token may attend to itself and to everything before it. The offset
argument is what a cached decoding step needs: one query row against all the
keys accumulated so far.

#+begin_src mlpl :tangle ../lib/qwen3/qwen3.mlpl
def u:qwen_causal_mask(positions, offset) {
  "A [queries, keys] matrix that is one where a query may attend to a key and zero where it may not. With an offset the queries are the last rows of a longer sequence, which is what a cached step needs.";
  rows = reshape(range(positions) + offset, [positions, 1]);
  columns = reshape(range(positions + offset), [1, positions + offset]);
  1 - lt(rows, columns)
}
#+end_src

One head. Scores are scaled by the square root of the head dimension so
their variance does not grow with width, disallowed positions are pushed far
negative before the softmax rather than after, and the result is a convex
combination of value vectors. The tests check that directly: give every
position the same value and the output must be that value.

#+begin_src mlpl :tangle ../lib/qwen3/qwen3.mlpl
def u:qwen_attention_head(query, key, value, head_dim, offset) {
  "One attention head over already-rotated queries and keys: scaled dot products, causal masking, row-wise softmax, and the value average.";
  scores = matmul(query, transpose(key)) / sqrt(head_dim);
  allowed = u:qwen_causal_mask(at(shape(query), 0), offset);
  matmul(softmax(scores * allowed - 1000000000 * (1 - allowed)), value)
}
#+end_src

Grouped-query attention. Queries get their own head each, keys and values
are shared between several, which is what makes the key-value cache small
enough to be worth keeping. Both are normalized per head *before* rotation,
which is the order the published weights were trained with.

The loop over heads is the one place this file indexes, and the comment in
the module header explains why.

#+begin_src mlpl :tangle ../lib/qwen3/qwen3.mlpl
def u:qwen_attention(config, weights, tables, x, offset) {
  "Grouped-query attention. Queries and keys are normalized per head before rotation, several query heads share each key and value head, and the heads are concatenated before the output projection.";
  positions = at(shape(x), 0);
  head_dim = config.head_dim;
  group = config.heads / config.kv_heads;
  queries = u:qwen_rms_norm(reshape(matmul(x, weights.wq), [positions, config.heads, head_dim]), weights.qn, config.eps);
  keys = u:qwen_rms_norm(reshape(matmul(x, weights.wk), [positions, config.kv_heads, head_dim]), weights.kn, config.eps);
  values = reshape(matmul(x, weights.wv), [positions, config.kv_heads, head_dim]);
  context = 0;
  head = 0;
  while lt(head, config.heads) {
    shared = floor(head / group);
    rotated_query = u:qwen_apply_rope(take(queries, 1, head), tables, offset);
    rotated_key = u:qwen_apply_rope(take(keys, 1, shared), tables, 0);
    piece = u:qwen_attention_head(rotated_query, rotated_key, take(values, 1, shared), head_dim, offset);
    context = if head {
      concat(context, piece, 1)
    } else {
      piece
    };
    head = head + 1
  };
  matmul(context, weights.wo)
}
#+end_src

SwiGLU: one projection is gated by the sigmoid-weighted other. The width
expands to the hidden size and the block projects it back.

#+begin_src mlpl :tangle ../lib/qwen3/qwen3.mlpl
def u:qwen_feed_forward(weights, x) {
  "SwiGLU: one projection is gated by the sigmoid-weighted other, then projected back.";
  gated = matmul(x, weights.gate);
  gated * sigmoid(gated) * matmul(x, weights.up)
}
#+end_src

Pre-norm residual: normalize, attend, add; normalize, feed forward, add.
Normalizing before rather than after each sublayer is what keeps the residual
path clean enough to train deep.

#+begin_src mlpl :tangle ../lib/qwen3/qwen3.mlpl
def u:qwen_block(config, weights, tables, x, offset) {
  "One pre-norm residual block: normalize, attend, add; normalize, feed forward, add.";
  attended = x + u:qwen_attention(config, weights, tables, u:qwen_rms_norm(x, weights.n1, config.eps), offset);
  attended + matmul(u:qwen_feed_forward(weights, u:qwen_rms_norm(attended, weights.n2, config.eps)), weights.down)
}

The same attention, over a history. Only the new positions' keys are rotated,
because past keys were rotated when they were new and rotation is a property
of a token's position, not of when it is read. Everything else is the
uncached function, which is deliberate: two implementations of attention
would be two chances to disagree, and the tests check they do not.

#+begin_src mlpl :tangle ../lib/qwen3/qwen3.mlpl
def u:qwen_attention_cached(config, weights, tables, x, past_keys, past_values, offset) {
  "Attention over a key and value history. The new positions' keys are rotated at their own offset and appended to what came before; past keys were rotated when they were new, so they are never touched again. Returns the output together with the extended history.";
  positions = at(shape(x), 0);
  head_dim = config.head_dim;
  group = config.heads / config.kv_heads;
  queries = u:qwen_rms_norm(reshape(matmul(x, weights.wq), [positions, config.heads, head_dim]), weights.qn, config.eps);
  fresh_keys = u:qwen_rms_norm(reshape(matmul(x, weights.wk), [positions, config.kv_heads, head_dim]), weights.kn, config.eps);
  fresh_values = reshape(matmul(x, weights.wv), [positions, config.kv_heads, head_dim]);
  rotated_keys = 0;
  shared = 0;
  while lt(shared, config.kv_heads) {
    piece = reshape(u:qwen_apply_rope(take(fresh_keys, 1, shared), tables, offset), [positions, 1, head_dim]);
    rotated_keys = if shared {
      concat(rotated_keys, piece, 1)
    } else {
      piece
    };
    shared = shared + 1
  };
  keys = if offset {
    concat(past_keys, rotated_keys, 0)
  } else {
    rotated_keys
  };
  values = if offset {
    concat(past_values, fresh_values, 0)
  } else {
    fresh_values
  };
  context = 0;
  head = 0;
  while lt(head, config.heads) {
    source = floor(head / group);
    piece = u:qwen_attention_head(u:qwen_apply_rope(take(queries, 1, head), tables, offset), take(keys, 1, source), take(values, 1, source), head_dim, offset);
    context = if head {
      concat(context, piece, 1)
    } else {
      piece
    };
    head = head + 1
  };
  {out: matmul(context, weights.wo), keys: keys, values: values}
}

def u:qwen_block_cached(config, weights, tables, x, past_keys, past_values, offset) {
  "One residual block over a key and value history, returning the block output and the extended history.";
  attended = u:qwen_attention_cached(config, weights, tables, u:qwen_rms_norm(x, weights.n1, config.eps), past_keys, past_values, offset);
  residual = x + attended.out;
  {out: residual + matmul(u:qwen_feed_forward(weights, u:qwen_rms_norm(residual, weights.n2, config.eps)), weights.down), keys: attended.keys, values: attended.values}
}

Generation with a key and value cache. The idea is simple: a token's keys
and values never change once computed, so recomputing the whole sequence for
every new token is waste. Keep them, and each step costs one position instead
of all of them.

What makes it worth writing carefully is that a cache is an optimization, so
it must be exact. The test that matters is not that it is fast but that its
scores are *identical* to recomputing from scratch, and they are: the measured
difference is zero, not small.

The honest result on cost, at the tiny configuration, is that caching is not
yet a saving. Eight cached steps take 14.4 ms against 13.6 ms to recompute,
because reading the stacked cache copies it. That is the same container cost
filed as R10, and the saving only appears once sequences and widths are large
enough to outweigh it.

The module needs the scanners and the model.

#+begin_src mlpl :tangle ../lib/generate/generate.mlpl

#+end_src

Every layer's history lives in one stacked array, because the language has
no list of records. This is the same constraint that made the forward pass
take its per-layer weights through a function reference, solved differently
because a cache is built up rather than looked up.

  s = shape(layer_state);
  piece = reshape(layer_state, concat([1], s));
  if layer {
    concat(stack, piece, 0)
  } else {
    piece
  }
}

One pass through every layer, extending the cache. With no offset it is a
prefill over a whole prompt; with an offset it is a single step. The two are
the same function because the causal mask already took an offset, which is
why that argument existed before there was anything to use it.

def u:gen_run(config, model, ids, cache, offset) {
  "Run a sequence through every layer, extending the cache. With no offset this is a prefill over the whole prompt; with one it is a single step over the tokens already seen. Returns the next-position scores and the new cache.";
  tables = model.rope;
  x = u:qwen_embed(model, ids);
  keys = 0;
  values = 0;
  layer = 0;
  while lt(layer, config.layers) {
    past_keys = if offset {
      take(cache.keys, 0, layer)
    } else {
      0
    };
    past_values = if offset {
      take(cache.values, 0, layer)
    } else {
      0
    };
    state = u:qwen_block_cached(config, call(model.layer_weights, layer), tables, x, past_keys, past_values, offset);
    x = state.out;
    keys = u:gen_stack_layer(keys, state.keys, layer);
    values = u:gen_stack_layer(values, state.values, layer);
    layer = layer + 1
  };
  logits = matmul(u:qwen_rms_norm(x, model.final_norm, config.eps), transpose(model.embedding));
  {logits: last_row(logits), cache: {keys: keys, values: values}, length: offset + tally(ids)}
}

def u:gen_greedy(config, model, prompt_ids, max_new, stop_id) {
  "Greedy decoding: prefill the prompt, then repeatedly take the highest-scoring token and feed it back. Stops at the stop id, which is not included, or at the token budget.";
  if tally(prompt_ids) {
    state = u:gen_prefill(config, model, prompt_ids);
    generated = [];
    produced = 0;
    running = 1;
    while running {
      next_id = u:gen_argmax_id(state.logits);
      if next_id - stop_id {
        generated = concat(generated, next_id);
        produced = produced + 1;
        if lt(produced, max_new) {
          state = u:gen_step(config, model, state, next_id)
        } else {
          running = 0
        }
      } else {
        running = 0
      }
    };
    ok({ids: generated, count: tally(generated), stopped: if tally(generated) - max_new {
          "stop token"
        } else {
          "budget"
        }})
  } else {
    err({kind: "empty_prompt", message: "generation needs at least one prompt token"})
  }
}

Validation before decoding. Given a header and a configuration, this checks
that every tensor the model needs exists with the right dtype and shape, and
produces a plan saying where each one lives. No tensor data is read here at
all.

That split is forced rather than chosen. Decoding the weights needs a bulk
byte-to-array conversion that the language does not have, filed upstream as
R11, so the step that reads tensor data is blocked. Everything up to that
point is not, and this file is that everything: on the real checkpoint it
validates all 310 tensors and arrives at 596,049,920 parameters by counting
from the configuration, which is exactly what the file's own header reports.

The header reader itself is vendored from `../demo-mlpl-libraries` at a
pinned revision with a hash lock, rather than rewritten here.

On 2026-09-22 the bf16 decoding step rechecked this boundary on Arch using
build =6d784660=, also the upstream HEAD at the time. The bulk conversion
probe still failed with an unknown-function error. That step therefore
recorded =unavailable=; these load plans are not a tensor decoder. The
[[file:bf16-handoff.md][core handoff]] specifies ordinary and special bf16 values, malformed
buffers, bulk-size acceptance, and the conditions for resuming the loader.

Relative weights need not sum to one. Divide by their maximum before summing so even weights near the f64 limit can be normalized.

#+begin_src mlpl :tangle ../lib/scaling/scaling.mlpl
def u:scaling_normalize(weights) {
  "Normalize finite nonnegative relative weights with positive mass; scaling by their maximum prevents overflow in the sum.";
  w = u:scaling_vector(weights, "weights")?;
  peak = reduce(:max, w);
  if reduce(:or, lt(w, 0)) {
    u:scaling_error("weights", "negative weights are not probabilities")
  } else {
    if gt(peak, 0) {
      scaled = w / peak;
      ok(scaled / reduce_add(scaled))
    } else {
      u:scaling_error("weights", "total probability mass must be positive")
    }
  }
}

The runtime gathers rows of a matrix. Treat a vector as a one-column matrix to reorder all entries in one operation.

Stable descending sorting favors lower token ids on ties. Each token survives when the mass before it is below =top_p=, keeping the token that crosses the threshold. An exact threshold ends the prefix. Invert the permutation after renormalization so indices still name vocabulary tokens. When =top_p= is one, return the normalized distribution directly so cumulative rounding cannot discard a tiny positive tail.

#+begin_src mlpl :tangle ../lib/scaling/scaling.mlpl
def u:scaling_nucleus(weights, top_p) {
  "Keep the smallest descending-probability prefix reaching top_p, retaining the crossing token; stable ties favor lower ids. Return renormalized probabilities in vocabulary order.";
  u:scaling_controls(1, top_p)?;
  probs = u:scaling_normalize(weights)?;
  if eq(top_p, 1) {
    ok(probs)
  } else {
    order = grade_down(probs);
    sorted = u:scaling_gather(probs, order);
    cumulative = running_sum(sorted);
    before = concat([0], compress(lt(range(tally(sorted)), tally(sorted) - 1), cumulative));
    kept = sorted * lt(before, top_p);
    ok(u:scaling_gather(kept / reduce_add(kept), grade_up(order)))
  }
}
#+end_src

Inverse-CDF intervals are half-open. A draw on a boundary belongs to the next positive interval, and zero-mass entries cannot be selected. If cumulative rounding leaves the final sum just below one, choose the last positive entry.

#+begin_src mlpl :tangle ../lib/scaling/scaling.mlpl
def u:scaling_pick(weights, uniform) {
  "Invert a categorical CDF at a supplied uniform in [0,1). Exact boundaries belong to the next positive interval; a rounding shortfall falls back to the last positive entry.";
  probs = u:scaling_normalize(weights)?;
  draw = u:scaling_scalar(uniform, "uniform")?;
  if (1 - lt(draw, 0)) * lt(draw, 1) {
    above = gt(running_sum(probs), draw);
    if reduce(:or, above) {
      ok(argmax(above))
    } else {
      ok(reduce(:max, compress(gt(probs, 0), range(tally(probs)))))
    }
  } else {
    u:scaling_error("uniform", "expected 0 <= uniform < 1")
  }
}

  "Sample with a KV cache and one seeded uniform stream for the entire token budget. Stop ids are excluded, zero budget avoids prefill, and decoding parameters accompany the result.";
  prompt = u:scaling_vector(prompt_ids, "prompt_ids")?;
  budget = u:scaling_scalar(max_new, "max_new")?;
  stop = u:scaling_scalar(stop_id, "stop_id")?;

  u:scaling_controls(temperature, top_p)?;
  if reduce(:and, eq(prompt, floor(prompt)) * (1 - lt(prompt, 0)) * lt(prompt, config.vocab)) {
    if eq(budget, floor(budget)) * (1 - lt(budget, 0)) {
      if eq(stop, floor(stop)) * (1 - lt(stop, 0 - 1)) * lt(stop, config.vocab) {
        positions = tally(prompt) + reduce(:max, [0, budget - 1]);
        if gt(positions, config.context) {
          u:scaling_error("max_new", "prompt and generated inputs exceed the context table")
        } else {
          generated = [];
          reason = "budget";
          if budget {
            uniforms = u:scaling_uniforms(s, budget)?;
            state = u:gen_prefill(config, model, prompt);
            produced = 0;
            running = 1;

    u:scaling_error("prompt_ids", "expected integer ids inside the vocabulary")

#+begin_src mlpl :tangle ../lib/scaling/consistency.mlpl
def u:scaling_vote_add(state, key) {
  "Increment one exact key or append it in first-occurrence order. Keys are newline-free normalized strings and counts form a parallel numeric vector.";
  n = tally(state.counts);
  keys = str_split(state.keys, "\n");
  found = 0 - 1;
  i = 0;
  while lt(i, n) {
    if str_eq(unwrap(list_get(keys, i)), key) {
      found = i;
      i = n
    } else {
      i = i + 1
    }
  };
  if lt(found, 0) {
    {keys: if n {
        str_concat(state.keys, str_concat("\n", key))
      } else {
        key
      }, counts: concat(state.counts, 1)}
  } else {
    {keys: state.keys, counts: state.counts + eq(range(n), found)}
  }
}

The observed winner is a plurality. Report a tie explicitly and choose its first-observed key. A winner is certain only when its count exceeds the strongest rival plus every remaining sample slot; an unseen rival has count zero. A strict inequality preserves tie reporting as well as winner identity.

#+begin_src mlpl :tangle ../lib/scaling/consistency.mlpl
def u:scaling_vote_report(state, remaining) {
  "Report the observed plurality, strict majority of valid votes, tied indices, and whether no allocation of remaining votes can create a tie or change the winner.";
  n = tally(state.counts);
  if n {
    best = reduce(:max, state.counts);
    ties = compress(eq(state.counts, best), range(n));
    winner = at(ties, 0);
    runner = reduce(:max, concat([0], compress(1 - eq(range(n), winner), state.counts)));
    answers = str_split(state.keys, "\n");
    {answer: unwrap(list_get(answers, winner)), votes: best, counts: state.counts, answers: answers, tie_indices: ties, tied: gt(tally(ties), 1), majority: gt(best, reduce_add(state.counts) / 2), certain: gt(best, runner + remaining), status: "answer"}
  } else {
    {answer: "", votes: 0, counts: [], answers: str_split("", ""), tie_indices: [], tied: 0, majority: 0, certain: 0, status: "no_valid_answers"}
  }
}

Require a nonempty vector of distinct exact integer seeds. Sorting the plan solely for duplicate detection leaves its original response order intact.

#+begin_src mlpl :tangle ../lib/scaling/consistency.mlpl
def u:scaling_sc_seeds(seeds) {
  "Validate a nonempty plan of distinct nonnegative exact integer seeds; duplicates would repeat a deterministic sample and inflate its vote.";
  plan = u:scaling_vector(seeds, "seeds")?;
  if reduce(:and, eq(plan, floor(plan)) * (1 - lt(plan, 0)) * (1 - gt(plan, 9007199254740991))) {
    n = tally(plan);
    duplicate = 0;
    if gt(n, 1) {
      ordered = u:scaling_gather(plan, grade_up(plan));
      left = compress(lt(range(n), n - 1), ordered);
      right = compress(gt(range(n), 0), ordered);
      duplicate = reduce(:or, eq(left, right))
    };
    if duplicate {
      u:scaling_error("seeds", "each sample must have a distinct seed")
    } else {
      ok(plan)
    }
  } else {
    u:scaling_error("seeds", "expected integer seeds between 0 and 2^53-1")
  }
}

Recompute the certainty bound even after an abstention because it reduces the remaining budget. Early-stop reports contain only observed counts and retain the full planned seed vector.

def u:scaling_consistency(problem, responder, seeds, options) {
  "Run a seeded responder plan, vote over normalized boxed answers, retain JSONL audit rows, and optionally stop when the current leader is unreachable. Counts describe observed samples, not hypothetical skipped votes.";
  prompt = u:scaling_cot_prompt(problem)?;
  plan = u:scaling_sc_seeds(seeds)?;
  settings = u:scaling_sc_options(options)?;
  total = tally(plan);
  state = {keys: "", counts: []};
  report = u:scaling_vote_report(state, total);
  trace = "";
  attempted = 0;
  valid = 0;
  early_stopped = 0;
  while lt(attempted, total) * (1 - early_stopped) {
    seed = at(plan, attempted);
    response = u:scaling_sc_respond(responder, prompt, seed, settings.decoding, attempted)?;
    extracted = u:scaling_vote_key(response);
    key = "";
    reason = "";
    accepted = is_ok(extracted);
    if accepted {
      key = unwrap(extracted);
      state = u:scaling_vote_add(state, key);
      valid = valid + 1
    } else {
      reason = err_message(extracted).kind
    };
    row = to_json({index: attempted, seed: seed, response: response, answer: key, accepted: accepted, reason: reason})?;
    trace = str_concat(trace, str_concat(row, "\n"));
    attempted = attempted + 1;
    remaining = total - attempted;
    report = u:scaling_vote_report(state, remaining);
    early_stopped = settings.early_stop * report.certain * gt(remaining, 0)
  };
  ok({answer: report.answer, votes: report.votes, counts: report.counts, answers: report.answers, tie_indices: report.tie_indices, tied: report.tied, majority: report.majority, certain: report.certain, status: report.status, attempted: attempted, valid: valid, rejected: attempted - valid, remaining: total - attempted, planned_seeds: plan, used_seeds: compress(lt(range(total), attempted), plan), early_stopped: early_stopped, stopped: if early_stopped {
        "certain winner"
      } else {
        "sample budget"
      }, trace_jsonl: trace, provenance: {build: settings.build, model_hash: settings.model_hash, template: u:scaling_cot_template(), base_template: u:eval_template_id(), voting: "normalized-boxed-v1", decoding: settings.decoding, early_stop: settings.early_stop}})
}

Even finite inputs can overflow during subtraction or summation. Detect that explicitly and return a range error rather than silently ranking infinities.

#+begin_src mlpl :tangle ../lib/scaling/scoring.mlpl
def u:scaling_score_finite(value, field) {
  "Reject arithmetic outside the finite f64 range instead of returning an accidental infinity or NaN.";
  if reduce(:and, flatten(eq(value - value, 0))) {
    ok(value)
  } else {
    err({kind: "score_range", field: field, message: "score arithmetic exceeded finite f64 range"})
  }
}
#+end_src

Subtract each row's maximum, compute the log of its shifted exponential sum, then subtract that normalizer. Taking the logarithm after softmax would lose low-probability tokens to underflow.

#+begin_src mlpl :tangle ../lib/scaling/scoring.mlpl
def u:scaling_log_matrix(logits) {
  "Stable row-wise log-softmax on a finite nonempty [positions,vocabulary] matrix, at model temperature one and without top-p filtering.";
  if str_eq(type_of(logits), "array") {
    if rank(logits) - 2 {
      u:scaling_error("logits", "expected a positions by vocabulary matrix")
    } else {
      dims = shape(logits);
      rows = at(dims, 0);
      vocab = at(dims, 1);
      if rows * vocab {
        u:scaling_score_finite(logits, "logits")?;
        maxima = reshape(reduce(:max, logits, 1), [rows, 1]);
        shifted = u:scaling_score_finite(logits - maxima, "logit differences")?;
        normalizer = reshape(log(reduce_add(exp(shifted), 1)), [rows, 1]);
        u:scaling_score_finite(shifted - normalizer, "log probabilities")
      } else {
        u:scaling_error("logits", "positions and vocabulary must both be nonempty")
      }
    }
  } else {
    u:scaling_error("logits", "expected a numeric matrix")
  }
}
#+end_src

The one-vector API uses the same matrix calculation through a single-row view.

#+begin_src mlpl :tangle ../lib/scaling/scoring.mlpl

#+begin_src mlpl :tangle ../lib/scaling/scoring.mlpl
def u:scaling_score_ids(ids, positions, vocab, field) {
  "Require one finite integer vocabulary id per aligned row before any gather.";

  if tally(tokens) - positions {
    u:scaling_error(field, "token count differs from the number of score rows")
  } else {
    if reduce(:and, eq(tokens, floor(tokens)) * (1 - lt(tokens, 0)) * lt(tokens, vocab)) {

    } else {

Row t predicts the supplied target id at t. Flatten the log matrix and gather one offset per row, without multiplying a full one-hot mask or interpreting a loop over the vocabulary.

#+begin_src mlpl :tangle ../lib/scaling/scoring.mlpl
def u:scaling_token_scores(logits, ids) {
  "Select each row's aligned target token log probability. Row t must already predict ids[t]; this function applies no implicit causal shift.";

  dims = shape(logs);
  rows = at(dims, 0);
  vocab = at(dims, 1);

Entropy is in nats. Normalize relative weights, remove zero entries, and then evaluate minus the probability-weighted logarithm; never form zero times log zero.

#+begin_src mlpl :tangle ../lib/scaling/scoring.mlpl

  positive = compress(gt(probs, 0), probs);
  u:scaling_score_finite(0 - reduce_add(positive * log(positive)), "entropy")
}

#+begin_src mlpl :tangle ../lib/scaling/scoring.mlpl
def u:scaling_heuristic(mean_logp, entropy, format_ok, weights) {
  "Higher-is-better heuristic: likelihood coefficient times mean logp minus entropy coefficient times entropy plus format coefficient times a caller-supplied binary format indicator.";
  likelihood = u:scaling_scalar(mean_logp, "mean_logp")?;
  uncertainty = u:scaling_scalar(entropy, "entropy")?;
  formatted = u:scaling_scalar(format_ok, "format_ok")?;
  if str_eq(type_of(weights), "record") {
    wl = u:scaling_score_weight(weights, "likelihood")?;
    we = u:scaling_score_weight(weights, "entropy")?;
    wf = u:scaling_score_weight(weights, "format")?;
    if (1 - gt(likelihood, 0)) * (1 - lt(uncertainty, 0)) * (eq(formatted, 0) + eq(formatted, 1)) {
      value = u:scaling_score_finite(wl * likelihood - we * uncertainty + wf * formatted, "heuristic")?;
      ok({score: value, version: "likelihood-entropy-format-v1", mean_log_probability: likelihood, entropy: uncertainty, format_ok: formatted, weights: weights})
    } else {
      u:scaling_error("heuristic", "require logp <= 0, entropy >= 0, and binary format_ok")
    }
  } else {
    u:scaling_error("weights", "expected an explicit heuristic coefficient record")
  }
}

Teacher forcing concatenates prompt and answer, removes the last token from model inputs, and removes the first from targets. The first answer is predicted at row prompt_length minus one. Mask all preceding prompt-only transitions. Tests compare with independent next-token prefix calls.

def u:scaling_best_of_n(problem, responder, scorer, seeds, options) {

  winner = 0;
  best = 0;
  response = "";

            } else {
              0
            }})?, "\n"));

Refinement consumes one initial seed followed by critique/revision pairs. Nonworse replacements become the next incumbent; regressions remain only in the trace. The explicit plan bounds the loop.

#+begin_src mlpl :tangle ../lib/scaling/refinement.mlpl
def u:scaling_refine(problem, responder, scorer, seeds, options) {
  "Generate and score an initial answer, then consume critique/revision seed pairs. Accept every nonworse revision; rejected text stays in the trace and never replaces the incumbent.";
  initial_prompt = u:scaling_cot_prompt(problem)?;
  plan = u:scaling_sc_seeds(seeds)?;
  settings = u:scaling_rank_options(options)?;
  rounds = (tally(plan) - 1) / 2;
  if eq(rounds, floor(rounds)) {
    response = u:scaling_rank_respond(responder, initial_prompt, at(plan, 0), settings, "initial", 0)?;
    score = u:scaling_rank_score(scorer, problem, response, settings, at(plan, 0), 0)?;
    trace = str_concat(to_json({stage: "initial", seed: at(plan, 0), candidate: response, score: score, incumbent: response, incumbent_score: score})?, "\n");
    accepted = 0;
    round = 0;
    while lt(round, rounds) {
      critique_seed = at(plan, 1 + 2 * round);
      revision_seed = at(plan, 2 + 2 * round);
      critique = u:scaling_rank_respond(responder, u:scaling_critique_prompt(problem, response)?, critique_seed, settings, "critique", round)?;
      candidate = u:scaling_rank_respond(responder, u:scaling_revision_prompt(problem, response, critique)?, revision_seed, settings, "revision", round)?;
      candidate_score = u:scaling_rank_score(scorer, problem, candidate, settings, revision_seed, round + 1)?;
      keep = 1 - lt(candidate_score, score);
      if keep {
        response = candidate;
        score = candidate_score;
        accepted = accepted + 1
      };
      trace = str_concat(trace, str_concat(to_json({stage: "revision", round: round, critique_seed: critique_seed, revision_seed: revision_seed, critique: critique, candidate: candidate, score: candidate_score, accepted: keep, incumbent: response, incumbent_score: score})?, "\n"));
      round = round + 1
    };
    ok({response: response, score: score, rounds: rounds, accepted: accepted, used_seeds: plan, trace_jsonl: trace, provenance: u:scaling_rank_provenance(settings, "boxed-refinement-v1", "accept-if-not-worse-v1")})
  } else { u:scaling_error("seeds", "expected an initial seed followed by critique/revision seed pairs") }
}

* What this adds up to

Reading in order, the document has built: a scanner layer that replaces a
regular-expression engine, extraction of a boxed answer, a thirteen-rule
normalizer, exact rational arithmetic, a recursive-descent evaluator, a
grader that is total on malformed input, a dataset loader that validates
before it returns, a harness that measures any responder with provenance
attached, the import that turns a six-megabyte tokenizer document into
tables a byte-level encoder can use, the encoder itself, the decoding and
prompt conventions that surround it, the decoder forward pass those ids
will run through, cached generation over it, the checkpoint validation
that will eventually feed it real weights, and seeded temperature/nucleus
sampling with categorical selection and cached decoding. Versioned reasoning
prompts and seeded self-consistency add answer voting, explicit abstentions,
and a stopping bound that preserves the winner and tie outcome.

Two runnable checks exercise all of it. =just verifier-demo= narrates the
pipeline over committed fixtures with a stand-in responder, and scores it
under both extraction modes to show the difference between a training reward
and a base-model measurement. =just math500-self-grade= is the honest one: it
grades all 500 answers of the real evaluation set against themselves and a
constant wrong answer, and reports 500 of 500 correct with no false
positives.

What is deliberately absent is as important. There is no symbolic
simplification, so =2x + 3x= and =5x= do not match. There is no regular
expression anywhere. Tiny synthetic weights generate tokens and prove the
forward, cache, and sampler contracts, but no real checkpoint data is loaded.
Bulk bf16 unpack now passes consumer acceptance on =cd3cd03f=; the
named-tensor loader now passes tiny-file and cached-forward tests. No tiny-model result is evidence of real-model
accuracy. Stable likelihood and entropy scoring now support
candidate ranking over fixtures and the tiny model. Bounded self-refinement
and best-of-N now have callback goldens and a scripted demo. Real-model
scaling measurements remain unavailable pending end-to-end viability.

  }
}

The end-to-end driver first loads the pinned native tokenizer. Its adapter
boxes the opaque handle when crossing MLPL function boundaries (R13), and
returns empty text locally for an empty id vector. It encodes the literal
bare-text prompt; no chat or thinking wrapper is applied to this base model.
The guard sizes the rotary tables, the safetensors validator checks the whole
checkpoint, and the named loader assembles resident role stacks and the tied
embedding/output matrix. The cached greedy loop prefills once, emits at most
two tokens and stops at id 151643. The report records ids, decoded text,
load/generation times, template version and seed 42 (unused by greedy).
The outer script records interpreter and artifact hashes and bounds the
process to 600 seconds and 32 GiB of virtual memory. Linux VmHWM sampling is
a lower bound on peak resident memory, not an exact peak measurement.

The exact driver is tangled here alongside the libraries so the executable
path and its explanation cannot drift. Run it through =just real-model-smoke=
only after the explicit weight fetch in the separate usage guide.
