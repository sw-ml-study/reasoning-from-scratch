Implemented the Qwen3 decoder forward pass in lib/qwen3/qwen3.mlpl with a deterministic seeded tiny model in lib/qwen3/tiny.mlpl. Covers RMSNorm over the last axis at any rank (the keepdim shape is derived from shape(x) with compress, so one function serves both a positions-by-width block and a positions-by-heads-by-head_dim one), split-halves rotary embedding with cosine and sine tables built once per configuration and halves split by compress along the last axis, grouped-query attention with queries and keys normalized per head before rotation and several query heads sharing each key and value head, causal masking with an offset argument that a cached step will need, SwiGLU, the pre-norm residual block, and logits through the tied embedding matrix. Written in whole-array operations throughout because element access copies the container; the per-head loop is the single documented exception and is exactly what upstream R3 would remove. Per-layer weights arrive through a function reference rather than a data structure, since the language has no list of records, which means the same forward pass will accept a safetensors loader unchanged. Seven property tests instead of golden numbers, including whole-model causality: appending tokens leaves earlier positions' logits unchanged to within 1e-6. Measured: 1.39 ms for four tokens, 2.3 ms for eight, 0.52 ms per attention layer. 71 tests pass, thirteen sources tangle, just check passes. Committed on main, not pushed.
